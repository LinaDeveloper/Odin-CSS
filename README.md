<h1>Beginner Landing Page Project</h1>
A lightweight, beginner-friendly landing page built with pure HTML5 and CSS3. This layout is modeled after a popular foundation project from The Odin Project curriculum to practice core web development concepts like flexbox, page structuring, and styling.

<h1>🚀 Overview</h1>
This project showcases a classic modern website layout divided into five main sections:

Hero Header: Logo, navigation links, main headline, call-to-action button, and image placeholder.

Information Grid: A row of featured items with rounded images and caption subtext.

Quote Section: A full-width quote block featuring a stylized testimonial.

Call to Action (CTA): A highlighted banner encouraging user sign-ups.

Footer: Simple copyright statement.

<h1>🛠️ Features & Learning Objectives</h1>
Pure CSS Layouts: Styled entirely with flexbox for easy alignment without complex frameworks.

Beginner-Friendly Code: Structured with straightforward class names and basic HTML elements for quick readability.

Zero Dependencies: Runs out of the box in any browser—no installation, build tools, or JavaScript required.
